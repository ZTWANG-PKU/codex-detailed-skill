# 逐图与代码审查协议

## 1. 建立论文证据地图

精读正文和补充材料后，先列出：研究问题、中心假设、样本/数据、主张、主图编号、补充证据、关键方法及代码实现。为每个主图建立从 `panel → 图注 → Results 段落 → Methods → Supplementary/Extended/Source Data → code/data` 的映射。

必须视觉检查图像本身；只读图注或正文不算逐图审阅。PDF 中图过小或被拆页时，渲染对应页并寻找出版社高分辨率图、Source Data 或原始补充文件。

## 2. 每个主图的 Story

每个 Figure 独立成一个完整故事块，顺序如下：

1. **本图要回答的问题**：它在整篇论文逻辑中承担什么任务。
2. **设计与前置条件**：样本、实验/分析流程、对照和相关方法。
3. **逐子图解析**：按 a、b、c……及可辨认 inset 顺序逐一讲解。
4. **证据合成**：各面板如何共同支持本图主张，哪些只提供描述性证据。
5. **关联证据**：对应的补充图表、Extended/Source Data、方法和代码。
6. **限制与替代解释**：本图能说明什么、不能说明什么。
7. **Story 总结与衔接**：一句凝练结论，以及它如何引出下一图。

## 3. 每个子图都要回答

- **是什么**：实验、样本、算法输出或示意图；数据来自哪里。
- **怎么看**：横纵轴、单位、颜色、形状、图例、分组、方向、空间尺度和统计符号分别代表什么。
- **比较什么**：对照与实验组、基线方法、时间点、区域、细胞类型或队列如何构成比较。
- **看到了什么**：主要趋势和有上下文的定量结果；报告 n、效应量、置信区间/误差条和统计检验（若原文给出）。
- **说明什么**：它支持哪一个局部主张，和相邻面板如何相互支撑。
- **不能说明什么**：因果边界、混杂、可视化局限、验证不足和可能的替代解释。
- **证据出处**：图注、正文段落、方法、补充材料、Source Data 或代码位置。

若图中存在未标字母的小块、嵌套图或多行/多列条件，按可辨认结构分别解释。确实无法辨认时写明具体障碍，不得自行命名或猜测。

## 4. 常见图形的审读重点

- 空间图：spot/cell/pixel 分辨率、切片与组织区域、比例尺、配准方式、色标是否跨图一致、相邻切片能否直接比较。
- UMAP/t-SNE：输入特征、批次校正、聚类/注释依据；二维邻近通常不能独立证明谱系、连续过程或生物距离。
- 热图/点图：行列含义、归一化/缩放、聚合层级、颜色与点大小、选择展示基因带来的偏倚。
- 火山图/差异分析：效应量阈值、校正后显著性、多重检验、供体还是细胞作为独立重复。
- 轨迹/拟时序：起点选择、方向性假设、分支稳定性和独立验证；拟时序不自动等于真实时间或谱系。
- 生存/临床模型：队列、终点、删失、HR/CI、协变量、训练与外部验证、校准和临床增益。
- ROC/PR/预测图：样本单位、阳性率、数据拆分、患者级泄漏、置信区间、基线、外部测试和阈值选择。
- 病理注意力图/显著图：可视化方法、分辨率、与病理标注的一致性；热区不等于机制解释。
- 网络/细胞通讯：配体受体数据库、置换背景、表达与真实相互作用之间的推断边界。
- 3D/连续切片：切片间距、变形、缺失组织、配准基准、误差传播、重建验证和伪连续结构风险。

## 5. 统计与研究设计复核

在逐图过程中持续检查：生物学重复与技术重复、配对结构、样本层级、功效、纳排标准、盲法/随机化、批次与中心效应、多重检验、效应量、缺失值、训练/验证/测试隔离、患者级泄漏、超参数选择、消融、敏感性分析和外部验证。

发现统计单位、图注、正文和方法不一致时明确指出，不替作者补全。

## 6. 补充材料审查

建立完整补充材料地图。每个 Supplementary/Extended Figure、Table、Note、Dataset 或 File 至少记录目的、支持哪一主张和关键结果。对直接支撑主图、方法有效性、质控、消融、敏感性或外部验证的补充面板，按主图同等深度解释，并嵌入对应 Figure Story。

不能只写“补充材料支持主文”。指出它是加强、限定、质疑还是改变主结论。

## 7. GitHub/代码审查

官方仓库存在时，不能只复述 README。审阅与论文主张相关的实际文件，至少覆盖：

- 仓库身份、license、commit/tag/release 和活跃状态；
- 安装环境、依赖、模型权重、随机种子和硬件要求；
- 数据预处理、样本拆分、归一化、特征选择和批次处理；
- 核心模型/算法、损失、默认超参数、训练和推理入口；
- 评价指标、基线、消融及生成论文图表的脚本；
- 示例数据、测试、配置、文档和从原始数据到主要结果的可运行链条；
- 与论文方法描述不一致、缺失、硬编码、潜在泄漏或不可复现之处。

将关键结果尽量映射到具体代码文件/目录。若仓库巨大，优先审阅决定主结论的路径，并说明未覆盖范围。没有官方仓库、链接失效或数据不公开时如实报告。

## 8. 从证据到新想法

新 idea 必须锚定论文证据或缺口，并写成可检验方案：假设、为何可能成立、最小数据/实验、对照、评价指标、成功判据、主要失败模式和备选路线。区分直接复用、跨癌种/平台推广、方法组合和真正的新假设。
